# Milestone 3 GOOJPRT Preparation

## Source Material

Reviewed local vendor archive:

`D:\Programming\BT_printer\3side\GOOJPRT-Printer-Driver-main`

The useful Android sources are in the old Eclipse project:

`MTP 标签label printer\MTP-2 BT SDK\PrinterLibs\src\com\lvrenyang`

Do not import the APK or old `printerlibs.jar` directly into PrintBridge. They target old Android versions, use static global transport state, and mix UI, protocol, and I/O. Port behavior into PrintBridge modules instead.

## Ported Into PrintBridge

- `GOOJPRT_LABEL` protocol added to core models.
- Default unverified GOOJPRT/MTP profile added for 58 mm / 203 DPI labels.
- GOOJPRT-compatible Bluetooth fallback already exists in `printer-bluetooth`: standard SPP UUID first, then secure/insecure attempts, then RFCOMM channel 1 fallback.
- Clean Kotlin `GoojprtLabelDriver` added in `printer-drivers`.
- GOOJPRT parser and preview path added in `simulator-core`.
- App UI can select `GOOJPRT_LABEL`, generate ready jobs, inspect preview, and send the generated bytes through existing transports.

## Milestone 3 Scope

1. Add TCP profile editor fields: host, port, connect timeout, write timeout.
2. Add Android USB-host module with device enumeration, permission request, endpoint detection, bulk write, timeout handling, and disconnect behavior.
3. Expand the ready-job screen into a compact label composer: text blocks, barcode, QR, rectangle/line, bitmap placeholder, element ordering.
4. Add protocol-specific preview for `GOOJPRT_LABEL` in the same visual preview surface as ESC/POS and TSPL.
5. Add regression tests for GOOJPRT malformed commands, bitmap payload length, QR/barcode null termination, and 64-byte Bluetooth chunks.
6. Run real-device checks:
   - Samsung -> Redmi virtual printer for `GOOJPRT_LABEL`.
   - TCP loopback simulator.
   - USB runtime only with a real USB printer or compatible USB serial printer attached.

## Current Limits

- GOOJPRT profile is marked `verified = false` until tested with a physical GOOJPRT/MTP printer.
- The label composer is still template-based; it is not a freeform visual editor yet.
- GOOJPRT label text is written as UTF-8 (`GoojprtLabelBuilder.zeroTerminated`), which is what the
  vendor SDK does; this is unverified on hardware along with the rest of the protocol.

## Delivered Since This Preparation Note

The items previously listed as future work are implemented and covered by tests; this file is kept
as the record of the vendor port rather than as a plan. Current state:

- TCP profile fields (host, port, connect timeout, write timeout) exist in the profile editor.
- `printer-usb` implements USB host printing: enumeration by writable bulk OUT endpoint, runtime
  permission request, bulk writes with a bounded deadline and partial-write retry.
- `printer-bluetooth` implements Bluetooth Classic SPP with a connect/write deadline.
- `GOOJPRT_LABEL` has a preview surface in the app's diagnostics tab.
- GOOJPRT malformed-command, bitmap-payload and QR/barcode termination cases are covered by
  `SimulatorTests`.

Still outstanding: real-device checks, which require physical printers.
