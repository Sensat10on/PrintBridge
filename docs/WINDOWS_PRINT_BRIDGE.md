# Windows Print Bridge

The Windows bridge lets Android send raw printer bytes to a Windows PC, then forwards them into a selected Windows print queue.

This is the path for Windows shared printers. Android prints to the PC over TCP, not directly to SMB.

## List Windows Printers

```powershell
.\gradlew.bat :windows-print-bridge:run --args="--list"
```

The default printer is marked with `*`.

## Start Bridge

Use the Windows default printer:

```powershell
.\gradlew.bat :windows-print-bridge:run --args="--port 9191"
```

Use a specific printer queue:

```powershell
.\gradlew.bat :windows-print-bridge:run --args="--printer ""Printer Name"" --port 9191"
```

Allow inbound TCP port `9191` in Windows Firewall when prompted.

## Android Setup

1. Keep the bridge process running on the PC.
2. Open PrintBridge on Android.
3. Form a ready job.
4. Tap `НАЙТИ СЕТЕВЫЕ ПРИНТЕРЫ`.
5. Select the candidate marked `PrintBridge Windows Bridge`.
6. Tap `ПЕЧАТАТЬ ПО TCP`.

## Notes

- The bridge forwards the generated bytes as an autosense print job.
- ESC/POS, TSPL, and GOOJPRT_LABEL bytes are preserved; conversion is not performed by the bridge.
- Windows queue behavior depends on the installed printer driver. Some office/GDI printers may expect rendered document formats instead of raw thermal-printer commands.
